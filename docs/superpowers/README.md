Was hier liegt, beschreibt, wie einmal geplant wurde — nicht, wie das Plugin heute
funktioniert. Die Inhalte sind bewusst nicht nachgepflegt: sie dokumentieren einen
Planungsstand und werden nur zum Nachvollziehen alter Entscheidungen aufbewahrt.
Die Unterordner `plans/` und `specs/` sind lokal und nicht versioniert.
